学校・市町村別CSV分割ツール

Version 1.0.0  正式配付版  
開発主体: Imamu-Lab

1. 概要

調査結果CSVを、学校別、市町村別、または1校指定で抽出するブラウザ用ツールです。調査用児童生徒番号の先頭6桁を学校コードとして使用し、学校コードExcelと照合します。

読み込んだCSVおよびExcelは利用端末のブラウザ内で処理されます。本ツールから外部サーバーへファイルを送信する処理はありません。

2. 主な機能

・小学校・中学校の自動判定
・可変列数CSVへの対応。96列、102列の調査CSVで動作確認済み
・UTF-8 BOM付き、UTF-8 BOMなし、Shift-JIS・CP932のCSV読込
・学校ごと一括出力
・市町村ファイル出力
・1校指定出力
・全データ、初回受検フラグ、最終回受検フラグによる抽出
・処理結果一覧CSVの生成
・UTF-8 BOM付き、CRLF形式でのCSV出力
・起動診断、エラーコード、件数整合性検査
・学校コードExcelにある6桁以外のコードを委員会コード等として除外
・国独、県立、その他の特殊区分で教育委員会名が空欄の場合の内部補完

3. 対応環境

・PC版 Microsoft Edge
・PC版 Google Chrome

スマートフォン、タブレット、その他のブラウザは動作保証外です。

5. 起動方法

1. 配付ZIPを展開します。
2. survey-csv-splitter.htmlをMicrosoft EdgeまたはGoogle Chromeで開きます。
3. 起動診断が正常であることを確認します。
4. 元データCSVと学校コードExcelを選択します。

6. 入力ファイル

元データCSV

必須列:

・調査用児童生徒番号_調査用児童生徒番号

任意の抽出対象列:

・初回受検フラグ
・最終回受検フラグ

列数は固定していません。重複した列名と元の列順を保持します。

学校コードExcel

必須シート:

・小学校コード一覧表
・中学校コード一覧表

各シートの2行目A列からD列には、所定の見出しが必要です。6桁のコードだけを学校コードとして使用します。

7. 出力形式

・文字コード: UTF-8 BOM付き
・改行: CRLF
・区切り: カンマ
・CSVの列順、列名、セル値を維持
・学校別一括と市町村出力では処理結果一覧CSVをZIPへ格納

8. 利用上の注意

・利用前に対象ファイルのバックアップを保管してください。
・本ツールは元のCSVおよびExcelを直接変更しません。
・出力後は、処理結果一覧、対象学校、件数、CSV内容を確認してください。
・出力ファイルは所属組織の情報セキュリティ規程に従って管理してください。
・共有端末では、ダウンロードフォルダー等に出力ファイルが残っていないか確認してください。
・個人情報を含むファイルを、許可されていない場所へ保存または送信しないでください。
